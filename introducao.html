Introdução ao HTML

Bem-vindo ao mundo do HTML!

O HTML (HyperText Markup Language) é uma linguagem de marcação
utilizada para criar páginas web.

enquanto o html faz a estrutura da página, o CSS (Cascading Style Sheets) é usado para definir o estilo e a aparência visual do conteúdo HTML.
O CSS permite controlar cores, fontes, layouts, espaçamento e outros aspectos visuais de uma página web, tornando-a mais atraente e agradável para os usuários.
